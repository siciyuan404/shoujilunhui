## 三台华为手机开启无线 adb（5555 端口）
- 设备与当前 WiFi IP 映射（DHCP，可能变动）：
  - HLK-AL00 / GDB4C19724002062 → 192.168.1.11:5555
  - JKM-AL00b / 2PF4C18B06000229 → 192.168.1.2:5555
  - ELS-AN00 / W9F0220331008745 → 192.168.1.8:5555
- 操作：先 `adb -s <serial> tcpip 5555`，等 adbd 重连稳定后 `adb connect <ip>:5555`。
- 坑：华为部分 ROM 在 `tcpip` 后 adbd 重启会闪断（设备短暂 not found），且 W9F 这类机型会直接断开 USB 只留 TCP 监听；`adb connect` 若在闪断窗口内执行会报 10060 超时，需等重连再连。
- 验证端口可用性用 `bash /dev/tcp/<ip>/5555`（PowerShell Test-NetConnection/Write-Host 在此环境无回显）。
- 注意：华为手机重启后 tcpip 失效，需重新设置；拔 USB 后多数华为网络 adb 仍保持（W9F 已验证）。
